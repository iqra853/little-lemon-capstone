# Little Lemon Restaurant - Table Booking Web App

This is the Front-End Developer Capstone project built with React. It allows users to view the Little Lemon restaurant landing page and reserve a table with real-time form validation and accessibility support.

## Features

- Responsive UX/UI following Little Lemon branding guidelines
- Semantic HTML5 structure and ARIA accessibility attributes
- Interactive table reservation form with input validation and edge-case handling
- Unit tests using Jest and React Testing Library

## Setup & Installation Instructions

1. Clone this repository:
   ```bash
   git clone <your-github-repo-url>
   ```
2. Navigate into the project directory:
   ```bash
   cd little-lemon-capstone
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
5. Run unit tests:
   ```bash
   npm test
   ```
